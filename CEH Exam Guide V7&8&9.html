Section 1: Trojan Exploitation (njRAT)

Goal: Configure a RAT client, infect a target, and execute post-exploitation commands.

1. Configure the Payload (Attacker Machine)

  1. Launch Tool: Open njRAT v0.8d.exe on Windows 11.
  2. Port Setup: Keep default port 5553 and click Start (or OK).
  3. Build Payload: Click the Builder button (bottom left).
  4. Builder Settings:
    • Host: Enter attacker IP (e.g., 10.10.1.11).
    • Port: 5553.
    • Victim Name: (Optional) e.g., Hacked.
    • ExeName: Explorer.exe (or Trojan.exe for Lab 4).
    • Directory: %TEMP%.
    • Checkboxes: Enable Randomize Stub and Protect Process [BSOD].
  5. Save: Click Build and save as Test.exe.

2. Establish Connection (Victim Machine)

  1. Transfer: Move Test.exe to the victim machine (Windows Server 2022).
  2. Execute: Run Test.exe on the victim machine.
  3. Verify: On the attacker machine, confirm the new connection appears in the njRAT GUI.

3. Post-Exploitation Actions

  • File Access: Right-click Victim → Manager → File Manager.
  • Command Shell: Right-click Victim → Manager → Remote Shell. Run ipconfig/all.
  • Spying: Right-click Victim → Remote Desktop or Remote Cam.
  • Keylogging: Right-click Victim → Keylogger.

Section 2: Virus Creation (JPS Virus Maker)

Goal: Create a destructive virus to disable system defenses on a target.

1. Configure Virus Options (Attacker Machine)

  1. Launch Tool: Open JPS.exe.
  2. Select Destructive Actions: Check the following boxes:
    • Disable Task Manager
    • Disable Windows Update
    • Disable Control Panel
    • Disable Drives
    • Hide Desktop Icons
    • Turn Off Windows Firewall & Defender
    • Auto Startup
  3. Set Trigger: Select the None radio button.

2. Advanced Configuration

  1. Access Next Page: Click the Right Arrow icon on the tool interface.
  2. System Lockout:
    • Change Windows Password: qwerty.
    • Change Computer Name: Test.
  3. Worm Mode: Check Enable Convert to Worm.
    • Name: fedevi.
    • Timer: 1 sec.
  4. Build: Select Architecture x86(64Bit) and click Create Virus!.

3. Verify Infection (Victim Machine)

  1. Execute: Run the created Server.exe on Windows Server 2019.
  2. Verify Symptoms:
    • Desktop goes blank.
    • Task Manager access is denied.
    • Restart required; login fails with the old password (must use qwerty).

Section 3: Static Analysis

Goal: Analyze malware file properties without executing it.

1. Online Hybrid Analysis

  1. Upload: Submit tini.exe to hybrid-analysis.com.
  2. Environment: Select Windows 11 64 bit.
  3. Analyze Report:
    • Check Threat Score (e.g., 100/100).
    • Identify classification (e.g., Trojan Tiny).
    • Review AV Results (e.g., CrowdStrike, MetaDefender).

2. ELF Analysis (Detect It Easy)

  1. Load File: Open ELF Test File in Detect It Easy (DIE).
  2. Identify Metadata:
    • File Type: ELF64.
    • Compiler: GCC.
    • Architecture: AMD64.
  3. Deep Inspection: Click the Entropy button to check packing status.

3. Disassembly (IDA Pro)

  1. Load File: Open face.exe in IDA Pro.
  2. View Assembly: Right-click in the IDA View-A window → select Text view.
  3. Trace Flow: Go to View → Graphs → Flow chart.
  4. Check Imports: Click the Imports tab to see API calls (e.g., Kernel32).

4. Code Analysis (OllyDbg)

  1. Load File: Open tini.exe in OllyDbg.
  2. Examine Activity:
    • View → Log (to see process creation logs).
    • View → Executable modules (to see DLLs like kernel32.dll).
    • View → Memory map (to see stack/heap allocation).

Section 4: Dynamic Analysis

Goal: Monitor a live malware infection to identify network ports and file system changes.

1. Port Monitoring (TCPView & CurrPorts)

[WARNING] Setup: Ensure Trojan.exe (from Lab 1) is running on the victim machine before starting.

  1. TCPView Analysis:
    • Launch tcpview.exe.
    • Locate Trojan.exe in the list.
    • Identify Connection: State should be Established. Note the Remote Address (10.10.1.11) and Remote Port (5553).
  2. CurrPorts Analysis:
    • Launch cports.exe.
    • Locate Trojan.exe. Verify Local Port and Remote Port match the attacker configuration.
    • Action: Right-click process → Close Selected TCP Connections (optional remediation).

2. Process Monitoring (Process Monitor)

  1. Launch Tool: Open Procmon.exe.
  2. Filter/Search: Scroll or use the filter function for Process Name contains Trojan.exe.
  3. Inspect: Double-click the process line to open Event Properties.
    • Path: Verify location (e.g., AppData\Local\Temp\Trojan.exe).
    • Modules: Check loaded DLLs in the Stack or Process tab.

Section 5: Network Sniffing

Goal: Perform active/passive sniffing, capture credentials, and detect sniffing attacks.

Lab 1: Active Sniffing (Flooding & Starvation)

Environment: Parrot Security (Attacker).

  1. MAC Flooding (macof):
    • Open Terminal: sudo su (pass: toor).
    • Run: macof -i eth0 -n 10.
    • Verify: Check Wireshark for random MAC/IP packets.
  2. DHCP Starvation (Yersinia):
    • Launch Interactive Mode: yersinia -I.
    • Configure: Press F2 (DHCP Mode) -> Press x (Attack Menu) -> Press 1 (Send DISCOVER packets).
    • Verify: Watch DHCP packet count rise. Press q to stop.

Lab 2: Sniffing Credentials & Remote Traffic

  1. Password Sniffing (Wireshark):
    • Attacker (Server 2019): Start Wireshark on Ethernet 2.
    • Victim (Win 11): Log into http://www.moviescope.com (User: sam / Pass: test).
    • Filter: Stop capture. Apply filter http.request.method == POST.
    • Find: Edit -> Find Packet -> String: pwd. Look in "HTML Form URL Encoded".
  2. Remote Sniffing (Remote Packet Capture Protocol):
    • Target (Win 11): Start service Remote Packet Capture Protocol v.0 (experimental) in services.msc.
    • Attacker (Server 2019): Wireshark -> Capture Options -> Manage Interfaces -> Remote Interfaces.
    • Add Host: IP: 10.10.1.11, Port: 2002, Auth: Jason / qwerty.
    • Start: Select the new remote interface and click Start.

Lab 3: Detecting Sniffing Attacks

  1. Detect ARP Poisoning (Wireshark):
    • Simulate: Use Cain & Abel (Configure Sniffer -> Scan MACs -> APR Tab -> Add Victims -> Start APR).
    • Detect: In Wireshark, go to Edit -> Preferences -> Protocols -> ARP/RARP.
    • Enable: "Detect ARP request storms" and "Detect duplicate IP address configuration".
    • Result: Analyze -> Expert Information -> Look for "Duplicate IP address configured".
  2. Detect Promiscuous Mode (Nmap):
    • Tool: Ubuntu Machine. Install: apt install nmap -y.
    • Scan: nmap --script sniffer-detect 10.10.1.19 (Target IP).
    • Result: Output should say _sniffer-detect: Likely in promiscuous mode.

Section 6: Social Engineering

Goal: Perform social engineering attacks (Credential Harvesting) and detect phishing attempts.

Lab 1: Credential Harvesting (SET)

Environment: Parrot Security (Attacker) & Windows 11 (Victim).

  1. Launch Tool: Open Terminal and run: 
    sudo su
setoolkit
  2. Configure Attack Vector: Select options in this order:
    • 1 Social-Engineering Attacks
    • 2 Website Attack Vectors
    • 3 Credential Harvester Attack Method
    • 2 Site Cloner
  3. Set Parameters:
    • IP Address: Enter your Parrot IP (e.g., 10.10.1.13).
    • URL to Clone: Enter http://www.moviescope.com.
  4. Execute:
    • Send the malicious link (your IP) to the victim (simulated via email).
    • When the victim logs in, credentials appear in the Parrot terminal.

Lab 2: Detect Phishing (Netcraft)

Environment: Windows 11.

  1. Install Extension: Install the Netcraft Extension on Firefox.
  2. Analyze Site: Visit a site (e.g., www.certifiedhacker.com) and click the extension icon to view the Site Report (Rank, Country, Host).
  3. Verify Blocking: Visit a known test phishing site (e.g., https://end-authenticat.tftpd.net/). Verify that Netcraft blocks it with a "Suspected Phishing" warning.

Lab 3: AI Phishing (ChatGPT)

Environment: Web Browser.

Use AI to generate convincing phishing templates (Disclaimer: For educational/testing purposes only).

  • Support Scam Prompt: 
    Pose as a genuine Microsoft customer support executive with imaginary name, write a concise mail stating that he/she has found suspicious login on user's account and ask them to reset the password on urgent basis. Provide the reset link at [Fake Reset Link].
  • IT Policy Update Prompt: 
    Write an email from a company's IT administrator to its employees letting them know that they need to install the latest security software. Provide a link where the employee can download the software. Let them know that all employees must complete the download by next Friday.
  • Impersonation Prompt: Use sample text from a target to instruct the AI to "Impersonate [Name]'s writing style...".
